双轨结构：主攻期 + 保温期

13 天集中攻下四个子题型，之后每天 15 分钟保温。

🔥 主攻期 第 1 – 13 天

每天约 3 小时投入判断推理。按"定义 → 类比 → 逻辑 → 图形"顺序推进——先拿下方法性强的题型，图形放最后，避免一开始受挫。

♻️ 保温期 第 14 天起 – 考前

每天 1 组题（约 15 分钟，必须限时）；每周 1 次完整 35 题限时组。图形推理可以隔天练，定义与逻辑必须天天见。
为什么必须保温：判断推理的规律是"记忆型"的——图形推理的试规律顺序、翻译推理的箭头方向，都很容易忘。而且它题量最大（35 题），手感一丢，考场上这一块会塌得最快。

05

解题总逻辑：每类题一把钥匙

图形

找规律

先看元素组成：相同→位置；相似→样式；凌乱→属性/数量。规律必须能解释所有图。

定义

找要件

把定义拆成 2–4 个要件（主体、对象、方式、目的），逐项比对，缺一个即排除。

类比

找关系

先造句找主干关系，再用二级辨析（词性、必然性、程度）区分近义选项。

逻辑

找链条

形式题翻译成箭头推理；论证题先找论点+论据，判断选项是搭桥还是拆桥。

共通心法：判断推理全部是"规则题"，只要有唯一规律能同时解释题干所有信息，就是它。凡是只能解释一部分的规律，都是错误规律。
选择题解法总则（全模块通用）：行测都是单选题，解析不走"一步步精算"。固定三步——①先排除明显错误项 → ②再缩小到 1–2 项 → ③后择优（仅在无法区分时才精确比对）。能排除的绝不硬算。

图形推理规律表（D9–D10 主攻）

解法就是"按顺序试规律"：先判断元素组成，再按表逐类排查。

① 位置规律 元素相同

平移：方向 + 步数（可能循环/递增）
旋转：顺/逆时针 + 角度（45°/90°/180°）
翻转：水平 / 垂直（会改变相对方向）
识别：元素种类和数量完全不变，只是位置变了。

② 样式规律 元素相似

遍历：每行/列元素齐全，缺什么补什么
加减同异：求同 / 求异 / 去同存异
黑白运算：按推导出的规则表计算
黑白运算必须先推导规则再套用，不能凭感觉。

③ 属性规律 元素凌乱

对称性：轴对称 / 中心对称 / 对称轴数量与方向
曲直性：全直 / 全曲 / 曲直混合
开闭性：开放 / 封闭图形
"凌乱图形"优先想对称——最高频的属性考点。

④ 数量规律 无其他规律

点：交点数 / 端点　线：直线/曲线/笔画数
面：封闭区域数量　角：直角/锐角/钝角
素：元素种类与个数
口诀：数"点线面角素"，按顺序试，找数列规律。

⑤ 空间重构

折纸盒：相对面（"Z 字端"）不能同时出现；相邻面看公共边/公共点
三视图：主视 / 俯视 / 左视
截面：正方体常见截面形（三角/矩形/五边形/六边形）
一笔画判定：奇点数为 0 或 2 才能一笔画成。
试规律的顺序：位置 → 样式 → 属性 → 数量 → 空间。一条规律必须能解释题干所有图形，只要有一张图不符合，就是错的规律，立刻换下一条。

逻辑判断速查卡（D4–D8 主攻）

翻译推理 必考

如果 A 就 B → A → B（充分条件前推后）
只有 A 才 B → B → A（必要条件后推前）
除非 A 否则 B → ¬A → B
A→B 等价于 ¬B→¬A（逆否等价）
口诀：肯前必肯后，否后必否前；否前肯后不确定。

真假推理

矛盾关系（必一真一假）：是/不是、所有/有的不、A→B 与 A且¬B
反对关系：两个"所有"必有一假；两个"有的"必有一真
先找矛盾定真假区间，再用剩余条件推断，最后假设验证。

加强削弱 必考

加强：搭桥 > 补充论据 > 排除他因
削弱：拆桥 > 举反例 / 另有他因 > 因果倒置
第一步永远是找论点和论据。搭桥/拆桥力度最强，无关项先排除。

定义判断 / 类比推理

定义：要件法（主体+对象+方式+目的+结果），缺一即排除
类比：全同 / 并列 / 包含 / 交叉 / 对应 / 语义 / 语法
类比的难点在二级辨析：种属 vs 组成、必然 vs 或然、词性是否一致。

高频坑点清单

  • 图形推理：找到的规律只能解释部分图形 → 一定是错规律，继续找。
  • 图形推理：旋转与翻转混淆——翻转会改变元素的相对方向。
  • 图形推理：黑白运算不推导规则、凭感觉选，错误率极高。
  • 图形推理：一笔画忘记判定（奇点数 0 或 2），误判为两笔。
  • 定义判断：看不清"问的是哪一个定义"，多定义题答非所问。
  • 定义判断：忽略要件中的限定词（"以…为目的""通过…方式"）。
  • 类比推理：只看词义、忽略词性（动词对名词）与必然性差异。
  • 翻译推理：用"否前"或"肯后"推出结论（无效推理）。
  • 翻译推理："除非 A 否则 B"翻译方向弄反。
  • 加强削弱：把无关项当成加强/削弱；忽略"最能"要比较力度。
  • 一拖五：跳读条件导致连环出错——必须先通读全部条件再做题。
  • 时间：图形推理单题超过 60 秒仍不跳，拖垮整个模块。
