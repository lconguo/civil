考情与本质：申论到底考什么

考试形式

项目内容
时长180 分钟（下午 14:00–17:00）
题量5 题（4 道小题 + 1 篇大作文）
分值小题合计 70 分 + 大作文 30 分
材料约 6000–8000 字，多则材料（给定资料 1、2、3……）

核心认知（先破除两个误解）

误解一："申论是作文比赛"。错。申论是材料题。小题答案的 70–80% 都藏在材料里，考的是"会不会找、会不会概括、会不会组织"，不是文采。
误解二："立意越高越好"。错。大作文跑题是最大的失分项。论点必须从材料里长出来，而不是自己另起炉灶讲大道理。
申论的本质＝四项能力的组合：审题（问什么）→ 找点（材料在哪）→ 加工（怎么组织）→ 表达（怎么写）。小题和作文都跑不出这四步。
70–80%小题答案来自材料原文
40 分钟读材料 + 审题时间
60 分钟大作文建议用时
≥ 65 分本计划目标分数

03

申论与行测如何并行

这是本计划最关键的设计。行测按"主攻 + 保温"双轨推进，申论则作为独立的第三条轨道全程并行，互不抢占。

两条轨道的分工

科目推进方式每日投入特点
行测主攻一个模块 + 保温其余2.5–3 小时可短期突破，靠限时训练
申论全程并行，匀速推进60–90 分钟不能突击，靠长线积累
为什么申论不能排成"阶段"：① 申论是 100 分，和行测等价，压到 11 月突击等于放弃一半分数；② 申论提分依赖语感 + 素材 + 手感，这三样都是"养"出来的，不是"背"出来的；③ 大作文每周都要写，断了就手生。
并行不冲突的原因：申论与行测用脑类型不同——行测是"快速判断"，申论是"深度加工"。放在同一天的不同时段，反而能互相调剂，不容易疲劳。
04

五大题型逐个拆解

申论所有小题都是这五类之一。每类给：识别问法 → 核心方法 → 作答步骤 → 易错点。

题型 1

归纳概括

15–20 分
识别问法

"概括/概述/简述……的主要做法 / 问题 / 原因 / 成效 / 特点 / 变化"。

核心方法

这是所有题型的地基——其他题型都是在概括基础上加分析或加对策。核心动作是"找点 + 合并同类项"。

作答步骤
  1. 审题：找什么对象？几个方面？限定范围是"给定资料几"？字数多少？
  2. 找点：逐段扫读，圈出与对象相关的关键词句
  3. 加工：同类合并，提炼出 3–5 个方面
  4. 书写：总括句 + 分条（"一是…；二是…"），每条尽量用材料原词
易错点

① 用词"自己想"而不是"材料里的"，踩不到分；② 要点漏（材料里出现了但没圈出来）；③ 不分条，写成一大段。

题型 2

综合分析

15–20 分
识别问法

"谈谈对'……'这句话的理解"；"对'……'这一观点的看法/评价"；"……带来的启示"。

核心方法

词句理解 = 释义 + 分析 + 结论；观点分析 = 表态 + 理由 + 结论。三段式结构，缺一段就丢分。

作答步骤
  1. 释义：这句话的意思是……（是什么）
  2. 分析：结合材料讲原因 / 表现 / 影响（为什么）
  3. 结论：因此应当……（怎么办 / 总结）
易错点

① 只解释不分析，字数不够分；② 忘记"结论"这一步；③ 观点分析不表态，含糊其辞。

题型 3

提出对策

15–20 分
识别问法

"请就……提出建议 / 措施 / 对策"。

核心方法

三种来源：问题反推（有问题→对着问题开药方）、经验借鉴（材料里别处的成功做法）、直接引用（材料已给出对策）。

作答步骤
  1. 先把材料里的"问题"找出来
  2. 每个问题对应一条对策
  3. 对策写成"主体 + 动作 + 内容/目的"
  4. 分条书写，用"一是…；二是…"
易错点

① 空泛——"加强管理"不算对策，要说清"谁来管、怎么管、管什么"；② 对策与问题不对应；③ 字数写超标。

题型 4

贯彻执行（应用文）

20–25 分★ 提分重点
识别问法

"写一份倡议书 / 公开信 / 讲话稿 / 工作方案 / 汇报材料 / 简报 / 宣传稿 / 短评 / 建议书"。

核心方法

就两件事：格式 + 内容。格式要素＝标题 / 称谓 / 正文 / 落款 / 日期（按文种取舍）；内容＝开头（背景或目的）+ 主体（材料里的要点）+ 结尾（呼吁或要求）。

作答步骤
  1. 审文种 → 定格式与语气（讲话稿口语化、汇报材料正式）
  2. 审对象 → 定称谓（"广大市民朋友""各位领导"）
  3. 从材料里提取要点，按逻辑排序写进主体
  4. 补上开头背景与结尾呼吁
易错点

① 格式要素漏（最常见）；② 文种语气错（把讲话稿写成公文）；③ 只写格式、要点没写全（这是最大的失分）；④ 对象搞错。

题型 5

文章写作（大作文）

30 分
识别问法

"以'……'为题 / 自拟题目，写一篇文章"。

核心方法

议论文，结构必须清楚：总—分—总。论点从材料里提炼，论据可以是"材料 + 积累"。不跑题 > 语言华丽。

作答步骤
  1. 从材料里提炼总论点（多在首尾材料与题干关键词里）
  2. 拆出 3 个分论点（并列或递进）
  3. 每段：分论点句 → 阐释 → 例证 → 回扣
  4. 开头亮明观点，结尾总结升华
易错点

① 脱离材料、自己另起炉灶（跑题）；② 没有分论点，想到哪写到哪；③ 只讲道理没有例证；④ 字数不足（一般要求 1000–1200 字）。

05

审题四步法（每道题都先做这一步）

申论丢分的第一大原因就是审题不清。审题花 1 分钟，能省 10 分钟的返工。

STEP 1

看作答范围

"根据给定资料 X"——只读指定材料，别扩大到全文，也别漏读。

STEP 2

看作答对象

概括什么？分析什么？对象是一个词还是一句话？对象决定找点方向。

STEP 3

看作答要求

准确 / 全面 / 有条理 / 简明，字数多少——这些是评分标准的明示。

STEP 4

定题型

判断属于五大题型哪一类，直接调用对应模板作答。

作答要求关键词解读（很关键）

要求真实含义怎么做
准确要用材料里的词优先摘抄材料原词原句，不要自己换词
全面要点要齐逐段扫读，宁多勿漏（在字数允许内）
有条理 / 有逻辑要分条分点用"一是…二是…"或"1. 2. 3."标序号
简明 / 言简意赅不能啰嗦去掉修饰，只留主干；每条一句话
观点明确要表态首句直接给出判断，别绕弯子
06

大作文框架（背下来直接用）

部分字数写什么
标题—观点式最佳（"以…夯实…""让…成为…"），避免空泛的"论…"
开头约 150 字背景/名言引入 → 亮明总论点（一两句话讲清立场）
分论点 1约 250 字分论点句 → 阐释 → 例证（材料/积累）→ 回扣
分论点 2约 250 字同上（并列或递进，不能重复）
分论点 3约 250 字同上
结尾约 100 字总结三个分论点 → 升华到时代/价值层面
分论点从哪来：从材料里找"三个角度"。常见角度组合：思想（认识）／制度（机制）／行动（落实）、个人／社会／国家、是什么／为什么／怎么办。选定一套就可以套用。
最省力的方法：平时就按这个框架反复写，把"分论点句 + 阐释"的句式练成模板（如"XX 是…的基础""夯实 XX，需要…"），考场上只需替换主题词。
07

三阶段时间安排（与行测并行）

申论的三个阶段与行测的推进节奏对齐，但内容独立。每日 60–90 分钟，坚持不中断。

阶段一 · 打地基（38 天）｜每日 60–75 分钟

按题型逐个突破，同时启动素材积累。这是申论唯一"学方法"的阶段。

W1第 1 周

申论入门 + 归纳概括打地基

  • 搞懂申论是什么、怎么考；学审题四步法
  • 精练归纳概括 3 道小题（先不限时）
  • 启动素材积累：每天摘 1-2 句金句
W2第 2 周

归纳概括强化 + 综合分析入门打地基

  • 归纳概括再练 3 道，开始限时（20 分钟/题）
  • 学综合分析（词句理解）的三段式
  • 精练综合分析 2 道
W3第 3 周

综合分析强化打地基

  • 观点分析 + 启示分析各练 2 道
  • 开始"精改"：每题对照参考答案，重写一遍要点
W4第 4 周

提出对策 打地基

  • 学"问题反推 + 经验借鉴"两种思路
  • 练 4 道对策题，每条写成"主体 + 动作 + 内容"
W5第 5 周

贯彻执行（应用文）重点

  • 掌握 5–6 种高频文种的格式与语气
  • 练 4 篇：倡议书 / 讲话稿 / 工作方案 / 汇报材料
W6第 6 周

文章写作方法论重点

  • 学大作文框架（总—分—总），练"提炼总论点 + 拆分论点"
  • 写 2 篇完整大作文（先不卡时间）

阶段二 · 成套提升（16 天）｜每日 90–120 分钟

从"单题"走向"整套"。核心动作是限时做完整套 + 精改。

频次内容说明
每周 2 套完整申论卷，限时 180 分钟安排在周末下午 14:00–17:00，贴合考试时段
每套之后精改：逐题对照参考答案，标出漏掉的要点，重写一遍精改比多做一套更重要
每周 2 篇大作文单独成篇（60 分钟限时）练速度与手感
每天素材积累 20 分钟摘金句 + 记案例
本阶段目标：整套申论能稳定在 60 分左右，小题要点覆盖率达 80%，大作文能在 60 分钟内成篇且不跑题。

阶段三 · 冲刺（21 天）｜每日 90 分钟

频次内容
每周 2–3 套全真模拟，严格 180 分钟，固定在下午 14:00–17:00 做
每周 2 篇大作文，只写已练熟的结构，不再尝试新写法
每天 20 分钟背热点主题 + 金句（新质生产力、基层治理、生态文明、文化自信等）
考前一周只回看错题卷与素材清单，不再做新题
冲刺期纪律：申论不押题、不背范文。押题押不中会崩，背范文会被判雷同。能做的是——把答题框架练到条件反射，把素材备足。

10

高频坑点清单

  • 审题漏范围：题目说"根据给定资料 3"，却用了全文的信息 → 踩不到分。
  • 字数不达标或超出：要求 300 字却写了 500 字，或只写 150 字，都要扣分。
  • 不分条、不分点：几百字写成一整段，阅卷老师找不到要点。
  • 小题整句照抄：不提炼、不合并，堆砌原文 → 要点重复且不精炼。
  • 小题用词"自己想"：不摘材料原词，换成自己的话 → 踩不到评分点。
  • 对策空泛："加强管理""提高认识"这类没有主体的对策，等于没写。
  • 应用文格式漏项：标题、称谓、落款缺一不可（按文种判断）。
  • 大作文跑题：脱离材料自己讲大道理，分数直接砍半。
  • 大作文无结构：没有分论点，想到哪写到哪。
  • 大作文只有道理没有例证：空对空，论证无力。
  • 小题超时挤占作文：大作文没写完 = 丢 30 分。
  • 卷面潦草：字迹工整、分条清晰，实际会加分（尤其小题）。

达标自检清单（可勾选）
